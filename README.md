# VfR Heilbronn U15 Statistik

GitHub-Pages-Version der Statistik-App, optimiert fuer iPhone, Android und Desktop.

## Veroeffentlichen

1. Neues GitHub-Repository erstellen.
2. `index.html`, `manifest.webmanifest` und `.nojekyll` in das Hauptverzeichnis hochladen.
3. Repository: **Settings > Pages**.
4. Unter **Build and deployment** die Quelle **Deploy from a branch** waehlen.
5. Branch **main** und Ordner **/(root)** waehlen, danach **Save**.

## iPhone

Die veroeffentlichte Seite in Safari oeffnen und ueber **Teilen > Zum Home-Bildschirm** installieren.

## Datenspeicherung

Spieler, Spiele und Statistiken werden im lokalen Browser-Speicher des jeweiligen Geraets gespeichert. Vor Browserwechsel, Geraetewechsel oder dem Loeschen von Safari-Websitedaten immer unter **Sicherung > Exportieren** eine JSON-Sicherung erstellen.

## Aktualisierung

Bei einer neuen Version nur die `index.html` ersetzen. Vorher sicherheitshalber die Daten in der App exportieren.
